Exam Answer Sheet Evaluation

1. Project Introduction

The Exam Answer Sheet Evaluation project aims to assist examiners in evaluating handwritten answer sheets using OCR and Natural Language Processing (NLP).

The system will extract handwritten text, compare student answers with model answers, and generate similarity scores to support the evaluation process.

2. Problem Statement

Manual checking of handwritten answer sheets takes considerable time and may produce inconsistent results. This project aims to make the evaluation process faster and more consistent using text extraction and answer similarity techniques.

3. Project Objectives

Study OCR techniques for handwritten text extraction.

Collect and organize sample handwritten answer sheets.

Explore image preprocessing methods.

Study text preprocessing and TF-IDF similarity.

Plan an answer scoring module.

Design a dashboard for examiners.

4. First Task: Dataset Collection and Preparation
